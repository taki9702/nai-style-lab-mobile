# NAI Style Lab Mobile

NovelAI Diffusion V5용 **작가 태그 그림체 탐색 앱**입니다. PC용 [NAI Style Lab v4.1.4](https://github.com/sdnwls/nai-style-lab)의 기능을 안드로이드 폰에서 그대로 쓸 수 있게 옮겼고, **그림체 뽑기**(작가 믹스 무작위 생성기)를 더했습니다.

## 설치

1. 폰에서 **[NAI-Style-Lab.apk 받기](https://github.com/taki9702/nai-style-lab-mobile/releases/latest/download/NAI-Style-Lab.apk)**를 누릅니다.
2. 다운로드한 파일을 엽니다. "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 이 출처 허용**을 켜고 설치합니다.
3. 앱을 열고 **설정 → NovelAI 연결**에 `pst-`로 시작하는 영구 API 토큰을 넣습니다.
   - 토큰 발급: NovelAI 웹 → ≡ → Account Settings → Get Persistent API Token

새 버전은 앱 안의 **설정 → 데이터 → 업데이트**에서 확인하고 받을 수 있습니다. 같은 서명으로 덮어서 설치하므로 데이터는 그대로 남습니다.

## 기능

| 탭 | 하는 일 |
|---|---|
| 그림체 뽑기 | 작가 풀에서 **작가 수 · 가중치 · 순서를 무작위로** 섞은 V5 프롬프트를 뽑습니다. 고른 작가는 **고정**해서 매번 들어가게 하고, 가중치도 랜덤 또는 고정값으로 정합니다. 위치는 자유, 맨 앞, 맨 뒤 중에서 고릅니다. 고정 작가의 가중치 범위를 따로 정하거나 전체 배율(예: ×0.7)을 걸 수 있습니다. 출력 틀(`{artist}` 자리)을 지정할 수 있고, 즐겨찾기와 기록도 남습니다. 결과는 눌러서 복사하거나 바로 그려서 대결에 넣습니다. |
| 대결 | 두 그림 중 마음에 드는 쪽을 고릅니다. **크게 비교**를 누르면 전체 화면에서 A/B를 넘겨 보며 고를 수 있고, 두 손가락으로 확대하면 두 그림에 같이 적용됩니다. 블라인드 모드, 되돌리기, 자동·전체 리그·상위 30% 모드를 지원합니다. |
| 진화 · 다듬기 | PC판과 같습니다. 상위 30% 조합을 섞어 세대를 진행하고, 같은 시드로 가중치만 바꿔 다듬은 뒤 다른 시드 3개로 최종 확인합니다. |
| 그림체 · 작가 | 조합 목록(티어 필터, 정렬, 부활, Elo 수정, 삭제)과 작가 점수를 봅니다. 그림은 갤러리에 저장하거나 공유할 수 있습니다. |
| 자유 생성 | 지금 설정 그대로 원하는 프롬프트를 한 장씩 그립니다. |
| PNG 프롬프트 보기 | NovelAI PNG를 고르면 프롬프트와 설정을 보여 주고, 그림 속 작가를 한 번에 등록합니다. |

## PC판과의 호환

- **데이터 내보내기 zip 형식이 PC판과 같습니다.** PC에서 내보낸 zip을 폰에서 불러올 수 있고, 반대 방향도 됩니다. state.json, images, API 키가 그대로 옮겨집니다.
- NovelAI 요청은 PC판 v4.1.4와 같은 필드로 보냅니다. Variety+, 품질 태그, UC 프리셋은 넣지 않습니다. 그래서 앱에서 만든 그림을 NovelAI 웹에서 Import Metadata로 불러오면 같은 그림이 나옵니다.
- Elo, 티어, 진화 선발, 작가 점수 계산은 PC판 코드를 그대로 옮겼습니다. 무작위 300개 사례에서 결과가 PC판과 같은지 비교해 확인했습니다.

## 만들기 (개발자용)

`main`에 푸시하면 GitHub Actions가 APK를 빌드해 Releases에 올립니다. 이때 `web/js/version.js`의 `VERSION`이 릴리스 번호가 됩니다.

```
web/            앱 화면과 엔진 (브라우저에서 web/index.html로 바로 열어 볼 수 있음)
web/js/backend  PC판 core.py · engine.py · bridge.py를 옮긴 코드, 저장소, NovelAI 통신
scripts/        웹 번들(esbuild)과 안드로이드 프로젝트 보정
android-res/    아이콘과 스플래시
signing/        APK 서명 키 (업데이트 설치가 되도록 항상 같은 키로 서명)
```
